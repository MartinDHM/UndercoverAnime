# 🕵️ Undercover Anime

**Undercover Anime** est une adaptation web du célèbre jeu d'ambiance **Undercover**, revisitée dans un univers inspiré des animes.

L'idée de ce projet est née d'un constat simple : je ne trouvais aucune version en ligne qui proposait l'expérience que je recherchais. Les interfaces étaient souvent vieillissantes, peu intuitives ou ne correspondaient pas à l'univers graphique que j'imaginais.

J'ai donc décidé de développer ma propre version en mettant l'accent sur une interface moderne, une expérience utilisateur fluide et une identité visuelle inspirée des animes.

---

## ✨ Fonctionnalités

- 🎌 Interface inspirée de l'univers des animes
- 👥 Configuration dynamique du nombre de joueurs
- 😈 Mode **Imposteur Assisté**
- 🤍 Mode **Mr.White**
- 🎮 Distribution automatique des rôles
- 📱 Interface responsive
- ⚡ Navigation simple et intuitive

---

## 🚀 Objectifs

À travers ce projet, je souhaitais :

- Repenser l'expérience utilisateur du jeu Undercover.
- Concevoir une interface plus moderne et immersive.
- Développer une application React dynamique.
- Créer un jeu simple à lancer entre amis.
- Travailler sur la gestion d'états et la logique de jeu.

## 🎯 Le défi

Le principal défi de ce projet n'était pas uniquement de recréer le jeu, mais de proposer une expérience que j'aurais moi-même aimé utiliser.

J'ai porté une attention particulière à :

- la simplicité de la navigation ;
- la rapidité de mise en place d'une partie ;
- une identité graphique cohérente ;
- une interface agréable et simple
